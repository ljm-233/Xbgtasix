## 中等（择要）

- `xmem` 统计记"请求字节"而非"提交字节"，`XMemFree` 先减计数再释放 → 预算按 stats 算会系统性高估（xmem.cpp:114-140）
- `xmem` ABA 假释放：延迟 double-free 若同址已重分配，会释放**活的**分配（xmem.cpp:129-140）
- `xmem` 持锁调 `logf` → stderr 被堵时全进程 `XMemAlloc/Free` 卡死（xmem.cpp:131）
- `d3d12_xs` 选卡无回落：换成独显失败时不做 retry(nullptr)（d3d12_xs.cpp:107）
- `forward.def` 裸写 `d3d12`（默认搜索序含 app 目录），与手写的 System32 路径不一致 → 可被 DLL 种植
- `trace.cpp` 被编进每个模块 → 每模块一套 FILE*/锁，"只报第一次"只在模块内生效，多模块日志行会交错
- `t3` 的 `expect_align()` 是实现的逐字复制，用被测代码算期望值（恒真）
- `t4` 只测索引 97，"整表指向同一槽"也能过（bindless 是核心卖点，必须多点验证）
- `t19` 配额断言 `delta >= n` 太松，多扣 100 MB 仍 PASS
- `t13` 的 `g_skip` 声明后从未使用 → 无 SKIP 分支；且它断言的是显卡能力而非兼容层
- `check_real_dlls.py` 的 `os.add_dll_directory()` 返回值被 GC → 动态加载时好时坏
- `analyze_exe.py` 把 `xcurl/libhttpclient/bink/amd_fidelityfx/xboxbvh` 当 Windows 原生 → 缺失被静默跳过
- `run_suite.sh` 默认输入是硬编码 `D:/GTA6/...`，换机器必然 FAIL 而不是 SKIP
